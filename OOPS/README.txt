ASSIGNMENT 8 - OOPS
===================

This folder contains nine separate JavaScript solutions:

1. Q1_StudentResultProcessing.js
2. Q2_OnlineFoodOrdering.js
3. Q3_ProductDiscountSystem.js
4. Q4_EmployeeInheritance.js
5. Q5_RideSharingApplication.js
6. Q6_ECommerceInventorySystem.js
7. Q7_BankingApplication.js
8. Q8_MovieTicketBookingSystem.js
9. Q9_FitnessAppAnalytics.js

How to run:
-----------
1. Install Node.js, if it is not already installed.
2. Open a terminal in this OOPS folder.
3. Run any question separately, for example:
   node Q1_StudentResultProcessing.js

You can also open a JavaScript file in VS Code and run it with Node.js.

Notes:
------
- Each question is in its own .js file.
- The examples use core JavaScript only; no external libraries are required.
- Q1 uses grade boundaries: A >= 80, B >= 60, C >= 40, otherwise F.
- Q6 defines low stock as fewer than 5 units.
- Q5 fare formula: Rs. 50 base fare + Rs. 12 per kilometre.
