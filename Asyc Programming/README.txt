ASSIGNMENT 6 - ASYC PROGRAMMING
================================

This folder contains 10 separate JavaScript solutions for Assignment 6.

Files:
1. Q1_AsyncCoffeeMaker.js
2. Q2_MicroVsMacroTasks.js
3. Q3_BugTrackerPromiseMigration.js
4. Q4_AsyncTimeoutRace.js
5. Q5_CallbackHellAndAsyncAwait.js
6. Q6_ProductCardFetcher.js
7. Q7_PromiseAllSettled.js
8. Q8_OrderRetryMechanism.js
9. Q9_DebuggingEventLoop.js
10. Q10_AsyncDeliveryPipeline.js

How to run:
-----------
1. Install Node.js (Node.js 18+ is recommended, especially for Q6 fetch()).
2. Extract this folder.
3. Open the folder in VS Code.
4. Open the terminal in this folder.
5. Run one file at a time, for example:
   node Q1_AsyncCoffeeMaker.js

Notes:
------
- Core JavaScript only; no frameworks or external packages.
- Random failures are intentional in several questions. Run again to see
  different success/failure outcomes.
- Q5 runs the nested-callback example and then the async/await example.
- Q6 fetches live product data from Fake Store API and requires internet access.
