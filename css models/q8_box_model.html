The CSS Box Model

Every element is a stack of four layers.

1. The four layers

margin
border
padding
content
  • Content – the text or image itself.
  • Padding – space between content and border.
  • Border – the line wrapping padding and content.
  • Margin – transparent space outside the border.

2. content-box vs border-box

Default

width: 200px + padding 20px×2 + border 5px×2 = 250px wide.

border-box

padding and border are inside the 200px = 200px wide.
