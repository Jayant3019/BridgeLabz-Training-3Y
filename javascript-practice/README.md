# JavaScript Assignment 1 — Solutions

This folder contains separate JavaScript files for Q1–Q10.

## Files
- Q1_LoginGreeting.js
- Q2_DataSummary.js
- Q3_ExpenseTracker.js
- Q4_AcademicEvaluator.js
- Q5_WeatherPlanner.js
- Q6_DiscountSystem.js
- Q7_GuessingGame.js
- Q8_SalaryProjection.js
- Q9_MathQuiz.js
- Q10_EligibilityValidator.js

## How to run
1. Install Node.js if it is not already installed.
2. Open this folder in VS Code.
3. Open Terminal → New Terminal.
4. Run a file, for example:

   node Q1_LoginGreeting.js

Run each of the other files by replacing the filename in the command.
