# Assignment 9 — jQuery

This folder contains 10 independent exercises. Every question has its own HTML and JavaScript file (`q1.html` + `q1.js`, ... `q10.html` + `q10.js`). `styles.css` is shared.

## Run
1. Extract the `jquerry` folder.
2. Open any question file (for example, `q1.html`) in a browser.
3. An internet connection is required because jQuery is loaded from the official jQuery CDN.

## Files
- Q1: Welcome page greeting
- Q2: Product highlight
- Q3: Interactive FAQ
- Q4: Special offer banners
- Q5: Team members directory
- Q6: Event subscription panel
- Q7: Course search/filter
- Q8: Dynamic blog posts
- Q9: Two isolated jQuery versions using `noConflict()`
- Q10: Registration form validation

## Notes
- Q10 uniqueness is demonstrated with a small in-memory list (`demo@example.com`); production uniqueness must be checked by a backend/database.
- Q9 uses jQuery 1.12.4 and 3.7.1 as separate aliases (`jq1`, `jq2`). The old version is included only to demonstrate `noConflict()` for this assignment.
