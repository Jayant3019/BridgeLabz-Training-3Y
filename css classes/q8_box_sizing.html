content-box vs border-box

Both boxes: width: 300px; padding: 30px; border: 5px

Default (content-box)

The width applies to the content only. Padding and border are added on top.

Total width = 300 + 60 + 10 = 370px

box-sizing: border-box

The width includes content, padding and border, so the box stays the size you set.

Total width = 300px

Why it matters

With border-box, adding padding never makes an element wider than planned, which makes layouts far more predictable. That is why most developers apply it globally with * { box-sizing: border-box; }.
