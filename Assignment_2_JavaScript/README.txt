ASSIGNMENT 2 — JAVASCRIPT SOLUTIONS

This folder contains one separate JavaScript file for each of the 10 questions.

HOW TO RUN WITH NODE.JS
1. Open a terminal or PowerShell in this folder.
2. Run a question, for example:
   node Q1_scope_conflict_resolver.js
3. Replace the filename with the question you want to run.

HOW TO RUN IN A BROWSER
1. Open a browser and press F12.
2. Select the Console tab.
3. Copy and paste the contents of one .js file, then press Enter.

NOTES
- Q3's random number changes each time it runs.
- Q4 generates eight new random scores each time it runs.
- Q8 checks the original cart total for the extra 5% discount.
- All solutions use core JavaScript only; no external libraries are required.
