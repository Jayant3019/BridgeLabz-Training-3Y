ASSIGNMENT 7 - DOM
==================

This folder contains all 9 DOM assignment solutions.

Each question has:
- One separate HTML file
- One separate JavaScript (.js) file

Shared stylesheet:
- styles.css

Questions:
1. Q1_ProductListManager.html / Q1_ProductListManager.js
2. Q2_CharacterCounter.html / Q2_CharacterCounter.js
3. Q3_MultiStepForm.html / Q3_MultiStepForm.js
4. Q4_ThemeSwitcher.html / Q4_ThemeSwitcher.js
5. Q5_ImageGallery.html / Q5_ImageGallery.js
6. Q6_StudentTableFilter.html / Q6_StudentTableFilter.js
7. Q7_MousePathLogger.html / Q7_MousePathLogger.js
8. Q8_CustomDropdown.html / Q8_CustomDropdown.js
9. Q9_FormSubmitBlocker.html / Q9_FormSubmitBlocker.js

How to run:
1. Extract the DOM folder.
2. Open the folder in VS Code.
3. Open any Qx_*.html file in a browser (or use Live Server).
4. The matching JavaScript file is loaded automatically.
5. Q5 uses online Picsum image URLs, so an internet connection is needed for those images.

No frameworks or external JavaScript libraries are used.
